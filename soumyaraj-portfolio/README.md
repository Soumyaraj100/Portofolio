# Soumyaraj Dutta Banik — Portfolio

A responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Customize before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the GitHub and LinkedIn URLs with your profiles.
3. Replace the `#` project links with your actual repositories/live demos.
4. Add a profile photo if you want one.

## Deploy
You can upload this folder to GitHub Pages, Netlify, Vercel, or Render as a static site.
